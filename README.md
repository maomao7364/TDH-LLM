# TDH-LLM: Data and Resources

This repository accompanies the manuscript **“TDH-LLM: A Pre-Trained Large Language Model with Temporal Decomposition and Horizon-Aware Decoding for Multi-step Traffic Flow Forecasting.”**

TDH-LLM integrates temporal decomposition, graph-based node representations, a pre-trained GPT-2 backbone, and horizon-aware decoding for multi-step traffic flow forecasting.

## Datasets

The experiments use two traffic datasets sampled at 5-minute intervals:

- **PeMSD7-derived:** A 50-station dataset adopted from prior research, distinct from the standard PeMS07 benchmark.
- **PeMS08:** A publicly available traffic dataset containing observations from 170 sensors.
